# TidyWeb Basic Python

**Thinking Through Your First Python Lab**

TidyWeb Basic Python is a gentle, narrative companion to FreeCodeCamp's
**Build a Travel Weather Planner** lab.

The guide is for the moment when a beginner has met Python's individual tools
but does not yet know how to turn a written problem into a complete program.
It teaches a reusable route:

1. Find the world.
2. Find the question.
3. Name the state.
4. Write the comment spine.
5. Translate the comments into Python.

## How to use it

Open the published guide and work through it alongside the FreeCodeCamp lab.
The yellow practice pads are places to plan and write an answer. They do not
run Python. Test the code in FreeCodeCamp's built-in Python editor.

## Run locally

No installation or build process is required. Open `index.html` in a modern
web browser.

The page uses Google Fonts when an internet connection is available. If the
fonts cannot load, the guide remains usable with its fallback fonts.

## About

This is a standalone learning guide. It is not connected to the TidyWeb Learn
SQL or Learn Python Data courses.
